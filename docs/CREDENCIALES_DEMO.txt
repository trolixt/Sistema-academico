Configuración local
-------------------
API: http://localhost:4000/api
Frontend: http://localhost:8443

El comando npm run seed crea una cuenta administradora solo si no encuentra
un usuario con nombre de referencia "admin". La contraseña inicial es
Admin2026* y el script muestra el ID generado. Si el usuario ya existe, el
script muestra su ID y no cambia su contraseña.

Este archivo no enumera cuentas de bases de datos activas o productivas. Las
cuentas reales se revisan desde Administración; las contraseñas existentes no
se pueden leer porque se guardan como hashes. Restablece una contraseña desde
el sistema cuando sea necesario.

Antes de usar las cuentas demo en un entorno compartido, cambia sus
contraseñas. Nunca copies aquí valores de backend/.env, claves reales ni
contraseñas de usuarios reales.
